## Contents

- `Figure_01.pdf` — system-model schematic. It is not generated by MATLAB; no artificial `Code_Figure_01.m` is included.

- `Master_Numerical_Data.mat` — shared numerical data generated by Fig. 2 and appended/used by later scripts.

## MATLAB execution

Place all files in one folder. In MATLAB, change the current folder to this repository and run:

```matlab
Run_All_Figures
```

Alternatively, run `Code_Figure_02.m` first and then `Code_Figure_03.m` through `Code_Figure_09.m` in numerical order.

### Dependency structure

`Code_Figure_02.m` is the primary numerical script. It defines the exact fixed MA realization, constructs the MA/PA deterministic spatial gains, performs the nonlinear-EH outage calculations, and writes `Master_Numerical_Data.mat`. The remaining figure scripts load this shared file so that the same position gains and baseline numerical realization are reused consistently.

## Exact MA realization

The MA realization is **deterministic**, not randomly regenerated. In `Code_Figure_02.m`, the complete one-dimensional MA setup is specified explicitly, including:

- reference coordinate `qMA0 = 0`;
- 41 candidate positions `qMA = (0:0.1:4)*lambda_c`;
- hop-specific complex path-weight vectors `a1` and `a2`;
- hop-specific propagation-direction projections `u1` and `u2`;
- unit-norm path-weight normalization;
- normalization of the fixed reference position to unit deterministic gain.

The resulting arrays and optimized locations are saved in `Master_Numerical_Data.mat`.

## Monte Carlo reproducibility

Monte Carlo simulations use explicit fixed seeds in the corresponding MATLAB scripts. The number of realizations and numerical parameter values are defined directly in the code and match the manuscript settings.

## Output naming

For archival consistency, the supplied scripts have been renamed to `Code_Figure_0N.m`, and their exported graphics are standardized to `Figure_0N.pdf` and `Figure_0N.png`. The numerical algorithms, formulas, parameter values, and plotted quantities were not intentionally changed by this packaging step.
